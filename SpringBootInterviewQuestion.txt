Spring Boot Interview Questions & Answers (9+ Years Experience)
1. What are the advantages of Spring Boot over traditional Spring Framework?

Answer:
Spring Boot simplifies Spring application development by providing:

Auto-configuration – Automatically configures beans based on classpath dependencies.
Embedded servers – Tomcat, Jetty, Undertow included; no WAR deployment required.
Starter dependencies – Simplifies dependency management.
Production-ready features – Actuator, metrics, health checks.
Opinionated defaults – Reduces boilerplate configuration.
Externalized configuration – Supports YAML, properties, env variables, config servers.
Rapid development – Minimal XML configuration.

For enterprise systems, Spring Boot significantly reduces setup time and improves maintainability.

2. Explain Spring Boot Auto Configuration.

Answer:
Auto Configuration automatically configures Spring beans based on:

Dependencies available in classpath
Existing bean definitions
Application properties

It works using:

@EnableAutoConfiguration
spring.factories / AutoConfiguration.imports
Conditional annotations:
@ConditionalOnClass
@ConditionalOnMissingBean
@ConditionalOnProperty

Example:
If spring-boot-starter-data-jpa is present, Spring Boot auto-configures:

DataSource
EntityManager
TransactionManager

We can exclude configurations using:

@SpringBootApplication(exclude = DataSourceAutoConfiguration.class)

5. What is dependency injection? Types?

Answer:
Dependency Injection (DI) is a design pattern where objects receive dependencies externally.

Types:
Constructor Injection (recommended)
Setter Injection
Field Injection (not recommended)

Preferred:

@Service
public class UserService {

    private final UserRepository repo;

    public UserService(UserRepository repo) {
        this.repo = repo;
    }
}

Benefits:

Loose coupling
Easier unit testing
Better immutability

11. Explain Spring Boot Security Architecture.

Answer:
Spring Security works using filter chain architecture.

Core Components:

Authentication
Authorization
SecurityContext
UserDetailsService
JWT/OAuth2

Flow:

Request enters filter chain
Authentication filter validates token
SecurityContext populated
Authorization checks performed

Modern approach:

@Bean
SecurityFilterChain security(HttpSecurity http) throws Exception {
    return http
        .csrf(csrf -> csrf.disable())
        .authorizeHttpRequests(auth -> auth
            .requestMatchers("/public/**").permitAll()
            .anyRequest().authenticated())
        .build();
}

15. What is Circuit Breaker pattern?

Answer:
Prevents cascading failures in distributed systems.

States:

Closed
Open
Half-open

Implementation using Resilience4j:

    return client.call();
}

Benefits:

Fault tolerance
Faster recovery
Prevents thread exhaustion

21. How do you handle exception globally?

Answer:

Using @ControllerAdvice:

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(Exception.class)
    public ResponseEntity<?> handle(Exception ex) {
        return ResponseEntity.internalServerError().body(ex.getMessage());
    }
}

Benefits:

Centralized handling
Standard error response
Cleaner controllers
22. Explain transaction propagation levels.

Answer:

Propagation	Description
REQUIRED	Default
REQUIRES_NEW	New transaction
SUPPORTS	Use existing if present
MANDATORY	Existing required
NEVER	No transaction allowed

Example:

@Transactional(propagation = Propagation.REQUIRES_NEW)
