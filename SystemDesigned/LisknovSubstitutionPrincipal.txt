//Lisknov Substitution Principal
Subclass should extend the capability of parent class but should narror it down
If class B is subtype of class A means class B extends A we shoulld able to replace object of A with B without Changes the Behaviour of the class
interface Bike {
    void turnOnEngine();
    void accelerate();
}

class MotorCycle implements Bike {

    boolean isEngineOn;
    int speed;

    public void turnOnEngine() {
        // turn on the engine
        isEngineOn = true;
    }

    public void accelerate() {
        // increase the speed
        speed = speed + 10;
    }
}
class BiCycle implements Bike{
public void turnOnEngine() {
        // turn on the engine
        throw new Assertion("There is no engine");
    }

    public void accelerate() {
        // increase the speed
        speed = speed + 10;
    }
}
