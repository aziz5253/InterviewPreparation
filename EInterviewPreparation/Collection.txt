ArrayList
Internal Working
Backed by a resizable array (Object[] elementData)
Initial capacity: 10 (Java 7)
When full → new capacity = old * 3/2 + 1
Elements added sequentially; reshifting on remove(index)
Time & Space Complexity
Operation	Time	Space

add(E)	Amortized O(1)	O(n)
add(i, E)	O(n)	O(n)
remove(i)	O(n)	O(n)
iteration	O(n)	O(1)

Custom Implementation (simplified)
java


class MyArrayList<E> {
    private Object[] data = new Object[10];
    private int size = 0;
    public void add(E element) {
        if (size == data.length) resize();
        data[size++] = element;
    }
    public E get(int i) {
        if (i >= size) throw new IndexOutOfBoundsException();
        return (E) data[i];
    }
    private void resize() {
        Object[] newArr = new Object[data.length * 3/2 + 1];
        System.arraycopy(data, 0, newArr, 0, size);
        data = newArr;
    }
}

3.2 Set Interface
Concept
No duplicates; unordered except for LinkedHashSet (insertion order) and TreeSet (sorted).

Implementations
Class	Underlying DS	Ordered	Duplicates?	Thread-Safe
HashSet	HashMap	No	No	No
LinkedHashSet	LinkedHashMap	Insertion	No	No
TreeSet	TreeMap	Sorted	No	No
HashSet
Internal Working
Backed by a HashMap
Hash function determines bucket index → stores elements as keys with fixed dummy value
Uses hashCode() and equals()
Time & Space Complexity
Operation	Time (avg)	Time (worst)	Space
add	O(1)	O(n)	O(n)
contains	O(1)	O(n)	O(n)
remove	O(1)	O(n)	O(n)
TreeSet
Internal Working
Backed by a TreeMap
Sorted using Red-Black Tree
Elements stored in natural or custom comparator order
Each insertion balances tree
Complexities
Operation	Time	Space
add	O(log n)	O(n)
remove	O(log n)	O(n)
contains	O(log n)	O(n)

3.3 Map Interface
Concept
Key-value pairs, unique keys.

Implementations
Class	Underlying DS	Ordered	Null Keys	Thread-Safe
HashMap	Hash Table + Linked List (Java 7)	No	Yes	No
LinkedHashMap	Hash Table + Linked List	Insertion	Yes	No
TreeMap	Red-Black Tree	Sorted	No	No
Hashtable	Hash Table	No	No	Yes
ConcurrentHashMap	Segmented Hash	No	No	Yes
HashMap Internal Working (Java 7)
Array of Entry<K, V>
Each bucket is a Linked List
Hash function: index = hash(key.hashCode()) % capacity
On collision → add at head of list (Java 8 uses tree after threshold)
Rehashing at 75% load factor
java


class Entry<K, V> {
  K key; V value;
  Entry<K,V> next;
}
Complexities
Operation	Avg Time	Worst	Space
get/put/remove	O(1)	O(n)	O(n)
iteration	O(n)	O(n)	O(n)

For Lists → manage array growth and shifting logic
For Sets → use hashing, avoid duplicates
For Map → maintain key-value entry list or table
For Trees → handle balance (AVL/Red-Black)
Handle equals(), hashCode(), and compareTo() carefully.
